Morse Coordinate Decoder

Load a recording of the in-game beeps. Each digit is 5 beeps, and each set is 10 digits: X (3), Y (3) and a 4-digit code, so 072 107 reads as X 0.72, Y 1.07. Sets are separated by a long pause. Your audio is decoded in this browser and never uploaded.

Recording

Drop an audio file here or choose one. MP3, WAV, M4A and OGG all work.

Decoder settings

Changing a setting re-decodes the current file. Any gap longer than the pause setting starts a new set, so lower it if two sets run together.
